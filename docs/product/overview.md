# 产品定位

UniPocket 是面向本科生、专科生及研究生的校园学习与生活工具 App，强调简单、实用、高效、有趣，以及对个人数据的保护。

## 用户需要解决的问题

- 课程、作业截止时间和考试日期分散，难以判断今天应该做什么。
- 点名、分组、抽签及日常决策需要临时寻找工具，重复输入名单。
- 考试报名和材料提交需要证件照、图片压缩、扫描及 PDF 处理，长期希望减少应用之间切换。

## 当前产品方向

先让学生通过一个应用查看当天课程、跟踪未完成事项，并使用轻量随机工具；首次安装后即可断网使用，不要求账号。首版范围与验收以[首版规格](../../.scratch/unipocket-v1/spec.md)为准。

长期扩展校园材料处理，保留 iOS 跨平台方向，未来引入后端。各项后续能力见[路线图](roadmap.md)，不作为首版开发要求。

## 品牌文案

产品名称统一为 UniPocket。早期口号“你的校园生活，一盒搞定。”作为待评估文案保留；它尚未随产品改名重新定稿，不作为必须展示的首版文案。
