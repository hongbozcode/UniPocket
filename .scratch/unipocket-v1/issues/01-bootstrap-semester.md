# 01: 从零建立 Flutter 应用，打通离线学期配置

**What to build:** 从零创建 Android 优先的 Flutter + Dart 应用，让用户无需账号和网络即可配置学期与校园时间，重启后继续使用。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## Acceptance criteria

- [x] 明确起点为零 Flutter 应用代码、零应用测试；创建可构建运行的工程，采用 Material 3 和 SQLite 本地持久化方向，具体依赖在引入前按项目 Context7 规则核实。
- [x] 提供首页、课表、工具、设置四个固定入口；首次运行和空状态能引导创建学期。其他尚未交付的功能不得伪装为可用。
- [x] 可创建多个学期并保留历史，配置第 1 教学周周一、总周数、每日节次起止时间及当前学期；输入错误有明确反馈。
- [x] 校园时区默认 Asia/Shanghai，可配置且界面注明；手机时区变化不改变校园日期时间含义。
- [x] 断网且无账号完成配置，重启后学期及设置仍保留；以用户操作到真实本地数据库建立首条行为验证路径。
- [x] 界面通过有意义的业务操作访问数据，业务规则与存储及平台细节分离；不预建账号、远程实现、同步引擎或机械转发层。

## 实施与验收约束

- 范围与行为以已确认的首版规格为准，使用领域词汇表术语；技术候选不视为已安装或验证。
- 复用现有视觉规范、效果图、HTML 样板参考及资源；所属流程缺少的表单、空状态、错误和确认状态随本任务补齐。Android 首版使用简化反馈，复杂动效及手册重建不进入本任务。
- 验证以用户操作到真实本地数据库的完整行为为主，仅在时钟、随机源、系统通知等外部边界控制环境；关键界面补充集成验证，通知另做真机检查。
- 按变更影响检查窄屏、长文本、文本缩放、安全区域和滚动可达性；记录实际运行证据及未验证项，HTML 截图不代表 Android 行为已实现。
- Status 是 triage 分类，不是执行完成状态；依赖任务完成后才进入可执行前沿。
