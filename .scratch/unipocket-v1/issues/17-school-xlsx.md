# 17: 真实学校 XLSX 导入与重复导入验证

**What to build:** 适配用户学校一种真实 XLSX 格式，让用户选择文件、预览纠错并安全导入，重复导入不制造相同安排。

**Blocked by:** 16: 导入候选结果的预览、纠错与原子提交

**Status:** ready-for-agent

**School adapter:** 已完成河北科技师范学院 `xskb.xlsx` 实际格式适配。用户于 2026-10-27 确认课程名与完整教师名单组成课程身份，目标学期与星期、起止节次、地点、精确教学周集合组成安排去重范围；无上课时间的备注课程供补齐或跳过。原件与效果示例保存在本地忽略目录。执行完成记录见下方 Comments 和检查记录；Status 保持 triage 含义。

## Acceptance criteria

- [x] 取得用户学校真实 XLSX 样例及必要字段含义确认；据此补齐课程身份识别、表头与合并单元格解析、候选行定位及精确去重规则后，方可转为 ready-for-agent。
- [x] 使用学校实际导出文件，不要求用户先改为自定义模板；不臆造学校名称、课程编号或宣称任意 XLSX 均可识别。
- [x] 真实文件解析接入任务 16 的目标学期、预览、逐项错误、修正／排除及一次保存流程。
- [x] 完全重复的安排默认跳过，重复与时间冲突分别呈现；再次导入同一真实文件不制造相同安排。
- [x] 用真实样例验证解析与持久化；在保留真实格式依据的前提下补充错误场景，验证取消、失败无部分写入及原数据完整性。
- [x] 在 Android 上验证真实文件选择、导入进度和结果；未取得样例不得用测试候选或虚构模板宣布学校适配完成。
