# 02: 手动录课与今日／周课表

**What to build:** 用户手动维护课程及其多个上课安排，在首页、今日视图和周课表查看当前学习安排。

**Blocked by:** 01: 从零建立 Flutter 应用，打通离线学期配置

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 可新增课程及教师信息，编辑课程基本信息；同一课程支持多个上课安排，每个安排独立设置星期、起止节次、地点和教学周。
- [ ] 教学周支持连续周、单周、双周及任意周选择，输入合法性有反馈。
- [ ] 周历支持切周、回本周及今日视图，按课程颜色区分；首页展示今日课程名称、时间和地点，并支持快捷添加课程。
- [ ] 仅当前学期课程参与首页展示；切换学期、无课日、无数据及长课程名称显示正确。
- [ ] 时间冲突提示后允许用户确认保留；保存重启后结果一致。
- [ ] 通过真实数据库验证周一基准、多安排、多地点和教学周选择；重复安排修改和删除影响由任务 06 交付。

## 实施与验收约束

- 范围与行为以已确认的首版规格为准，使用领域词汇表术语；技术候选不视为已安装或验证。
- 复用现有视觉规范、效果图、HTML 样板参考及资源；所属流程缺少的表单、空状态、错误和确认状态随本任务补齐。Android 首版使用简化反馈，复杂动效及手册重建不进入本任务。
- 验证以用户操作到真实本地数据库的完整行为为主，仅在时钟、随机源、系统通知等外部边界控制环境；关键界面补充集成验证，通知另做真机检查。
- 按变更影响检查窄屏、长文本、文本缩放、安全区域和滚动可达性；记录实际运行证据及未验证项，HTML 截图不代表 Android 行为已实现。
- Status 是 triage 分类，不是执行完成状态；依赖任务完成后才进入可执行前沿。
