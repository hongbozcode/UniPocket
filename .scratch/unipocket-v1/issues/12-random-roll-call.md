# 12: 随机点名与持久化抽取轮次

**What to build:** 用户保存多份点名名单，重复或不重复抽取，并跨页面和重启续接本轮进度。

**Blocked by:** 01: 从零建立 Flutter 应用，打通离线学期配置

**Status:** ready-for-agent

## Acceptance criteria

- [x] 提供工具页入口，支持多名单命名保存和编辑；同名成员独立保留，可通过学号或备注区分，不与其他工具共享名单。
- [x] 支持重复／不重复模式，等概率从有效候选中抽取；不重复模式按成员身份记录已抽和剩余候选。
- [x] 离开页面及重启后保留抽取轮次；抽完后需主动开始新一轮，修改名单前提示重置影响。
- [x] 触发时确定结果，简化反馈完成才提交且一次操作仅提交一次；取消未完成操作不消耗轮次。
- [x] 播放期间锁定编辑、模式切换和重复触发，保留返回取消；姓名及学号或备注对应同一成员且完整可读。
- [x] 真实数据库与可控随机源验证同名、不重复、轮次耗尽、主动重置、取消和重启续接。
