# 13: 抽签与持久化签池轮次

**What to build:** 用户保存多个签池，重复或不重复抽签，并完整查看签文和续接抽取轮次。

**Blocked by:** 01: 从零建立 Flutter 应用，打通离线学期配置

**Status:** ready-for-agent

## Acceptance criteria

- [x] 提供工具页入口，多签池可命名保存和编辑；重复签文提示，不擅自按文字合并，不跨工具共享。
- [x] 支持重复／不重复抽签，候选项等概率；不重复进度离页及重启后保留，耗尽需主动开始新一轮，修改签池前确认重置。
- [x] 可重复模式展示完整签池，不显示耗尽进度。
- [x] 触发时确定结果，反馈完成提交一次；进行中锁定编辑、模式切换及重复触发，返回取消不消耗轮次。
- [x] 采用简化反馈，长签文完整可读，不用默认示例长度限制输入；取消或完成后清理临时状态。
- [x] 真实数据库与可控随机源验证轮次、重复项、重启续接、取消及主动重置。
