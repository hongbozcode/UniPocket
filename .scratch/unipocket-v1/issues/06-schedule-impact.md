# 06: 重复安排变更与课程删除影响处理

**What to build:** 用户修改重复安排或删除课程前理解影响，并自主处理失去原课次关联的例外。

**Blocked by:** 03: 学习任务完整管理；05: 单次调课与停课

**Status:** ready-for-agent

## Acceptance criteria

- [x] 支持修改重复上课安排，预览对既有调停课的影响并保留仍有效的例外。
- [x] 失去原课次关联的例外由用户选择保留为独立补课或删除，不静默丢弃。
- [x] 删除课程前说明影响，确认后清理课程、安排及例外；关联 DDL 解除课程关联并保留。
- [x] 取消影响确认不改变数据；冲突可提示后确认保留。
- [x] 真实数据库验证关系变更、独立补课、删除后 DDL 保留及重启一致性；课程提醒清理由任务 08 联动完成。

## 实施与验收约束

- 范围与行为以已确认的首版规格为准，使用领域词汇表术语；技术候选不视为已安装或验证。
- 复用现有视觉规范、效果图、HTML 样板参考及资源；所属流程缺少的表单、空状态、错误和确认状态随本任务补齐。Android 首版使用简化反馈，复杂动效及手册重建不进入本任务。
- 验证以用户操作到真实本地数据库的完整行为为主，仅在时钟、随机源、系统通知等外部边界控制环境；关键界面补充集成验证，通知另做真机检查。
- 按变更影响检查窄屏、长文本、文本缩放、安全区域和滚动可达性；记录实际运行证据及未验证项，HTML 截图不代表 Android 行为已实现。
