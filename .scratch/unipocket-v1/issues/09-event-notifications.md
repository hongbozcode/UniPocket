# 09: 倒计时事件提醒

**What to build:** 用户获得倒计时当天的本地提醒，跨学期事项继续按自身日期提醒。

**Blocked by:** 04: 倒计时事件完整管理；07: DDL 提醒与通知权限反馈

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 复用任务 07 通知能力，默认事件当天校园时间上午 9 点，每项一个提醒，可修改或关闭。
- [ ] 编辑或删除事件后更新未来提醒，过去提醒明确提示且不补发。
- [ ] 切换当前学期不取消 DDL 和倒计时事件的未来提醒。
- [ ] 真实数据库、可控时钟和通知边界验证默认时间、编辑删除及跨学期保留，并完成 Android 真机事件提醒验证。

## 实施与验收约束

- 范围与行为以已确认的首版规格为准，使用领域词汇表术语；技术候选不视为已安装或验证。
- 复用现有视觉规范、效果图、HTML 样板参考及资源；所属流程缺少的表单、空状态、错误和确认状态随本任务补齐。Android 首版使用简化反馈，复杂动效及手册重建不进入本任务。
- 验证以用户操作到真实本地数据库的完整行为为主，仅在时钟、随机源、系统通知等外部边界控制环境；关键界面补充集成验证，通知另做真机检查。
- 按变更影响检查窄屏、长文本、文本缩放、安全区域和滚动可达性；记录实际运行证据及未验证项，HTML 截图不代表 Android 行为已实现。
- Status 是 triage 分类，不是执行完成状态；依赖任务完成后才进入可执行前沿。
