# 18: 完整本地备份与覆盖恢复

**What to build:** 用户主动导出全部本地数据，并在干净安装中安全覆盖恢复、重建未来提醒。

**Blocked by:** 08: 有效课程提醒；09: 倒计时事件提醒；15: 工具发现与首页常用入口

**Status:** ready-for-agent

**Implementation:** 已完成（2026-10-27，Android 模拟器与真实 SQLite 验证；实体手机通知验收仍待用户执行）。Status 保留 triage 含义。

## Acceptance criteria

- [x] 备份覆盖全部学期、课程和安排、调停课及独立补课、DDL、倒计时、提醒配置、工具列表、未完成轮次和应用设置，包括收藏及最近使用。
- [x] 只做完整导出和覆盖恢复，不做数据合并或自动备份；核心数据不主动上传。
- [x] 恢复前校验文件，再明确提示覆盖并要求确认；取消、无效文件或恢复失败不损坏当前数据。
- [x] 干净安装恢复后关系和轮次一致，重启后仍可继续使用。
- [x] 成功恢复后按有效数据重建未来提醒，不补发过去提醒；系统权限使用当前手机实际状态，不恢复旧设备权限。
- [x] 导出和恢复有清晰进度与结果反馈；真实数据库验证失败完整性，并在 Android 上验证文件操作和恢复后提醒。
- [x] 不以任务 17 为前置；先用手动录入的完整领域数据验证，真实导入数据的迁移联验由任务 19 完成。
