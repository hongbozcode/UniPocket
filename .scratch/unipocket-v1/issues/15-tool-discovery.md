# 15: 工具发现与首页常用入口

**What to build:** 用户通过搜索、收藏和最近使用找到六项已上线工具，并从首页快速重复使用。

**Blocked by:** 10: 掷骰子与抛硬币；11: 自定义转盘；12: 随机点名与持久化抽取轮次；13: 抽签与持久化签池轮次；14: 随机分组

**Status:** ready-for-agent

## Acceptance criteria

- [x] 工具页仅展示六项已上线工具，支持搜索、全部／收藏／最近入口及相应空状态。
- [x] 收藏和最近使用状态持久化，重启后保留；各入口能进入正确工具。
- [x] 首页接入常用工具，完整顺序为今日课程、未完成任务、近期事件、常用随机工具。
- [x] 各工具在各自任务完成时已有可操作入口，本任务补齐统一发现体验。
- [x] 通过真实数据库和界面集成验证搜索、收藏、最近记录、首页进入及空状态，滚动末项可触达。

## 实施与验收约束

- 范围与行为以已确认的首版规格为准，使用领域词汇表术语；技术候选不视为已安装或验证。
- 复用现有视觉规范、效果图、HTML 样板参考及资源；所属流程缺少的表单、空状态、错误和确认状态随本任务补齐。Android 首版使用简化反馈，复杂动效及手册重建不进入本任务。
- 验证以用户操作到真实本地数据库的完整行为为主，仅在时钟、随机源、系统通知等外部边界控制环境；关键界面补充集成验证，通知另做真机检查。
- 按变更影响检查窄屏、长文本、文本缩放、安全区域和滚动可达性；记录实际运行证据及未验证项，HTML 截图不代表 Android 行为已实现。
- Status 是 triage 分类，不是执行完成状态；依赖任务完成后才进入可执行前沿。
