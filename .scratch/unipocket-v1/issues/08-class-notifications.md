# 08: 有效课程提醒

**What to build:** 当前学期变更后的有效上课实例产生正确的未来提醒，不残留旧安排通知。

**Blocked by:** 06: 重复安排变更与课程删除影响处理；07: DDL 提醒与通知权限反馈

**Status:** ready-for-agent

## Acceptance criteria

- [x] 复用任务 07 接通的通知能力，课程默认提前 10 分钟，每项一个提醒，可修改或关闭。
- [x] 调课、停课、独立补课、重复安排修改和删除课程后正确更新或撤销未来提醒。
- [x] 切换当前学期后仅当前学期有效课程参与课程提醒，不残留旧学期课程通知。
- [x] 过去提醒不补发并有明确反馈；校园时间含义不随手机时区变化。
- [ ] 通过真实数据库、可控时钟及通知边界验证所有变更，在 Android 真机验证课程送达和旧提醒撤销。

## 实施与验收约束

- 范围与行为以已确认的首版规格为准，使用领域词汇表术语；技术候选不视为已安装或验证。
- 复用现有视觉规范、效果图、HTML 样板参考及资源；所属流程缺少的表单、空状态、错误和确认状态随本任务补齐。Android 首版使用简化反馈，复杂动效及手册重建不进入本任务。
- 验证以用户操作到真实本地数据库的完整行为为主，仅在时钟、随机源、系统通知等外部边界控制环境；关键界面补充集成验证，通知另做真机检查。
- 按变更影响检查窄屏、长文本、文本缩放、安全区域和滚动可达性；记录实际运行证据及未验证项，HTML 截图不代表 Android 行为已实现。
- Status 是 triage 分类，不是执行完成状态；依赖任务完成后才进入可执行前沿。
