# 11: 自定义转盘

**What to build:** 用户命名保存自己的转盘选项列表，重启后再次使用并获得等概率结果。

**Blocked by:** 01: 从零建立 Flutter 应用，打通离线学期配置

**Status:** ready-for-agent

## Acceptance criteria

- [x] 提供工具页入口，支持多组选项列表的命名保存、读取和编辑；不跨工具共享。
- [x] 重复文字给予提示，不擅自合并或暗中改变候选项；空列表不可抽取，单选项正确落位。
- [x] 候选项等概率，固定指针最终对应文字结果；触发时确定结果，反馈中不重新抽取且防止重复触发。
- [x] 使用简化反馈并处理取消；选项长文本、窄屏与文本放大可读。（用户本轮要求按源动效还原，已采用约 3.1 秒六圈减速反馈。）
- [x] 真实数据库验证重启保留，可控随机源验证有效候选和指针结果一致，无隐藏权重或指定结果。

- 范围与行为以已确认的首版规格为准，使用领域词汇表术语；技术候选不视为已安装或验证。
