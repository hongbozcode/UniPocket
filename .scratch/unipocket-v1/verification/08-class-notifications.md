# 任务 8 检查记录

日期：2026-10-25。范围：[有效课程提醒](../issues/08-class-notifications.md)。用户确认本次使用模拟器，Android 真机验收后续完成。

## 实现范围

- 复用任务 7 的系统通知边界及 Android `AlarmManager`，未新增依赖或安装开发环境。每门课程保存一个提前分钟数（默认 10，0 表示上课时，null 表示关闭），各次有效上课分别产生一个提醒；配置随 SQLite 持久化，schema 7 → 8。
- 仅当前学期参与课程提醒；重复安排、单次调课／停课、独立补课、删除课程、切换学期、更改校园时区或学期节次后，从已提交数据重算。调课通知身份按原课次，独立补课按独立身份区分，同日多个实例不会合并；学期范围外补课仍参与。
- 校园日期时间使用 IANA 校园时区转换为绝对时刻，不读取手机本地时区。过去及恰好到达的提醒不补发，课程表单和保存反馈注明已过次数、未来次数与真实通知状态。
- DDL 和课程按独立范围更新；一个范围的平台调用失败仍尝试另一个范围。保存、删除与平台失败分别反馈，SQLite 已保存数据不回滚。重试从真实数据重建提醒，不恢复旧安排。
- 课程详情提供提醒开关、提前分钟数与校园时间预览；已有通知状态卡继续提供权限和系统设置入口。切换学期不撤销独立或关联 DDL 的提醒，删除课程仍保留 DDL。
- 按用户本轮追加要求，通知正文使用自然中文：普通课程“11月1日 08:00 上课，地点：A101。”、调课“已调至……”、独立补课“补课时间：……”，DDL“11月1日 23:59 截止，记得按时完成。”；系统通知不显示时区标签，校园时区仍在设置与表单说明中保留。
