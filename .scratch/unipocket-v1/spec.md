# UniPocket 首次试用版

Status: ready-for-agent

## Problem Statement

大学生的课程、作业截止时间与考试日期分散在不同地方，难以迅速判断今天该去哪上课、还有哪些事项没完成。课堂点名、分组和日常决策又需要单独寻找工具并重复输入名单。用户希望在不注册、没有网络时仍可可靠地使用一个应用，保存自己的学习安排与工具数据，并在换机时主动迁移。

## Solution

以 Android 为首个平台，交付完全离线的 UniPocket：集中展示每日课程、未完成学习任务与倒计时事件，支持手动录课及用户学校一种实际 XLSX 格式导入、单次调停课、本地提醒、六项随机工具和完整本地备份恢复。采用首页、课表、工具、设置四个入口，清新蓝紫色浅色卡片风格。

首版面向个人开发与真实学生试用，不以完整校园材料处理工具箱为交付前提。应用架构方便后续后端演进，但不预建未使用的远程或同步体系。

## Implementation Decisions

### 交付与模块

- Flutter + Dart、Android 优先、Material 3；首版无需账号或网络，数据本地持久化。保留未来 iOS 方向，首版不承诺 iOS 发布。
- 按学习管理、学校课表导入、随机工具、备份恢复、系统提醒和界面组织职责。界面调用业务操作，业务规则与数据库和平台细节分离。只建立解决当前复杂度的模块，不机械堆叠转发层。
- 本地结构化存储采用 SQLite 方向。Riverpod、go_router、Drift 及本地通知插件为已有技术候选，版本、具体集成与兼容性在实施前核实，不视为已安装或已验证。
- 后端接入保留清晰的模块接口，但不预建空远程实现、通用多源框架或同步引擎。未来账户归属、同步冲突及服务协议另行设计。

### 学习模型与时间

- 学期记录第 1 教学周周一、总周数和每天的节次时间；允许多个学期，只有用户指定的当前学期参与首页课程及课程提醒。
- 课程包含多个上课安排；安排分别表达星期、节次、地点和选中的教学周。连续周、单双周是选择方式，不是互斥数据模型。
- 上课实例是具体日期的一次上课。单次调课可跨周并保留原实例关联；停课不删除整门课程。首页与提醒使用变更后的有效实例。
- 修改重复安排时保留已有例外并展示影响；失去原始课次关联的例外由用户选择独立补课或删除，不静默丢弃。
- 时间冲突可确认保存。删除课程前说明影响，删除其安排、例外和课程提醒，关联任务解除课程关联后保留。
- 校园时区统一配置，默认 Asia/Shanghai，界面注明；手机时区改变不改变校园日期时间的含义。每个事件单独时区不进入首版。
- DDL 标题、截止时间、可选课程和备注独立管理；仅选日期时显示 23:59。手动状态为未完成或已完成，逾期由时间计算，完成可撤销。
- 倒计时按校园时区的日历日期计算天数，而非把小时差除以 24；当天显示“就是今天”，过期进入历史，支持置顶，不和 DDL 互相创建。

### XLSX 导入

- 适配用户学校一种真实格式，不要求自行填写标准模板。样例尚未提供：不能臆造字段、课程编号、学校名称或假定任意 XLSX 均可识别。
- 输入为学校文件与目标学期，先输出候选课程／安排、错误、重复与冲突预览；用户修正或排除错误项后确认，一次写入选中内容。取消或失败不能留下部分导入数据。
- 完全重复的安排默认跳过，冲突与重复分别展示；重复导入同一文件不得制造相同安排。
- 课程身份识别、合并单元格及表头解析、候选行定位和精确去重键均等待真实样例；自动创建课程编号方案未获采纳。可先实现预览与提交的行为，但不能以虚构模板通过学校适配验收。

### 提醒

- 课程默认提前 10 分钟、DDL 提前 1 天、倒计时当天上午 9 点，每项一个提醒，可修改或关闭。提醒时间已过则提示，不补发旧提醒。
- 调停课、删除、切换当前学期以及恢复后按有效数据更新未来课程提醒；DDL 和倒计时按自身日期，不随学期切换消失。
- 通知未启用不阻断数据管理；显示状态并提供系统设置入口。保存成功与提醒启用分开表达，不承诺平台在任何设备状态下必然准时送达。

### 随机工具

- 六项为转盘、点名、分组、抽签、单个六面骰和硬币。候选项等概率，不允许隐藏权重或指定结果，骰子／硬币不保存历史。
- 转盘选项、点名名单、分组名单、签池可分别命名保存，暂不共享。重名成员保留独立身份，用学号或备注区分；重复文字提示但不直接按姓名合并。
- 点名和抽签支持可重复／不重复。不重复从本轮剩余候选项中选择，持久化轮次；全部抽完需用户主动开始新一轮，修改名单提示重置进度。
- 随机分组先打乱再分配。按组数时人数最多差 1；按每组人数上限时尽量均衡，例如 10 人每组最多 4 人得到 4、3、3。不含指定同组或避开同组。

### 数据、交互与质量

- 备份覆盖全部学期、课程与安排、调停课／独立补课、DDL、倒计时、提醒配置、工具列表及未完成轮次、应用设置；只做完整导出和覆盖恢复，不做数据合并。
- 恢复先校验再提示覆盖，无效文件不改变当前数据；成功后重新安排未来提醒，不补发过去提醒。系统权限不从旧设备恢复，使用当前手机状态。
- 首页按今日课程、未完成任务、近期事件、常用随机工具排序；逾期醒目标识。DDL 和倒计时可从首页及课表页进入。工具页仅显示已上线工具，保留搜索、收藏和最近使用入口。
- 视觉遵循[统一设计规范与资源索引](../../docs/product/design.md)：浅蓝白底、蓝紫圆角卡片、课程识别色、局部纸感与活泼贴纸；效果图、HTML 样板运行截图、交互说明及素材构成视觉依据。HTML 动效提供展示参考；正式 Android 端采用简化反馈，复杂动效后置。
- 核心数据不主动上传，用户主动导出。导入、备份等耗时操作不阻塞正常反馈，错误清晰呈现；不在此规格虚构性能指标或最低系统版本。

## Testing Decisions

- 测试边界已由用户确认：主要从应用用户操作到持久化结果验证完整行为，采用真实本地数据库；时钟、随机源及系统通知仅在外部依赖处控制，通知另做 Android 真机验证。优先一个共同的应用行为层入口，不为各层创建平行的模拟测试体系。
- 好测试断言用户可见状态、持久化结果、失败时的数据完整性及平台交互结果，不锁定内部方法调用顺序、私有结构或数据库表名。界面关键流程补充集成验证，不仅测试模拟数据库。
- 当前仓库没有应用代码、现有测试或可复用测试先例。本节定义实施时需要建立的验证，不代表测试已经通过。

| 测试范围 | 必须验证的外部行为 |
| --- | --- |
| 首次运行与持久化 | 断网、无账号完成首版操作；保存后重启仍可读取 |
| 学期与课表 | 周一基准、任意周／单双周、多个安排与地点；切换当前学期后仅有效课程参与首页和提醒 |
| 校园时间 | 更改手机时区不改变校园安排；跨午夜的倒计时按日历日期计算 |
| 调停课 | 跨周调课保持原实例关联且不改目标周原课程；停课取消该次显示与提醒 |
| 重复安排修改 | 例外保留和失去关联时的用户选择；不静默删除补课 |
| 删除与任务 | 删除课程移除课程提醒但保留独立化的 DDL；完成、撤销与逾期判定 |
| 真实 XLSX | 用用户提供的样例验证解析、错误修正、排除、重复跳过和冲突确认；取消／失败无部分写入 |
| 提醒 | 可控时钟验证默认时间、过期不补发及变更后未来提醒；通知禁用有可见状态且不阻断管理 |
| 倒计时 | 当天文案、过期历史、置顶和编辑删除，不产生 DDL |
| 随机工具 | 可控随机源验证有效候选范围、按成员身份不重复、重名保留、轮次重启续接及主动重置 |
| 分组与公平 | 每个成员恰好出现一次、人数边界、10 人上限 4 得到 4/3/3；验证随机选择规则，不用一次随机频率断言宣称公平 |
| 备份恢复 | 干净安装完整恢复、关系与轮次一致、无效文件不破坏原数据；未来提醒重建且权限来自当前设备 |
| 界面 | 四入口、首页顺序、空状态、导入确认、删除影响和恢复覆盖反馈，无未上线工具占位 |

发布前在约定 Android 真机上完成通知实际送达、权限关闭、数据持久化、导入及恢复流程验证；模拟通知成功不能替代真机结果。具体机型在发布验证前确定，学校样例未提供时不得宣布整版验收完成。

## Out of Scope

- 证件照、扫描、图片压缩、图片转 PDF、现有 PDF 合并与编辑等所有文件处理工具；照片／扫描的本地、后端或混合方案待定。
- 旧 XLS、CSV、PDF／图片课表识别、教务系统导入、任意学校通用识别或用户自定义字段映射。
- 注册登录、云数据库、同步、云备份、协作、在线投票、公开活动、聊天和社交。
- 深色主题、复杂动画、随机结果分享、骰子／硬币历史、多个骰子、权重配置、指定结果、跨工具名单共享、高级分组约束。
- 应用内“减少动效”模式及系统减少动效设置适配；HTML 演示中的同名选项仅辅助观看，不转为应用功能要求。
- 每年重复倒计时、多次提醒、事件独立时区、备份合并和自动备份。
- iOS 首次发布，以及预先搭建未使用的远程或同步基础设施。
